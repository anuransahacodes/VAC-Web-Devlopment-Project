# 🚀 EVENTO: Responsive Event Management Platform

## ✨ Project Summary
**EVENTO** is a premium, single-page website prototype for an event organization company. It is built entirely on the frontend using **HTML5**, **CSS3**, and **Vanilla JavaScript**. The project features a modern, high-contrast **Dark Theme** and a fully responsive layout using CSS Grid and Flexbox, ensuring optimal viewing across all devices.

## 🌟 Key Features

* **Modern Design:** Sleek Dark Mode UI contrasting with a striking **cyan/blue accent** (`#00d4ff`) for a premium aesthetic.
* **Dynamic Image Slider:** Custom-built image carousel in the hero section using **pure JavaScript** for a high-impact portfolio showcase.
* **Fully Responsive:** Layout adapts perfectly to all screen sizes (mobile, tablet, desktop) using **CSS Media Queries**.
* **Interactive UI:** Includes polished effects like **Smooth Scrolling** and a subtle glassmorphism/blur effect on the fixed navigation bar.
* **Modular Grids:** Clear display of Services and Price Packages using **CSS Grid** for organization.
